# Sistemastuberiasserie
"Sistemas de tuberías en serie"
Presentación HTML para el curso de Mecánica de Fluidos de la Universidad de América, preparada por el Ph.D. Juan Sandoval Herrera para la clase del 22 de octubre de 2026.

Contenido:
La presentación contiene 22 diapositivas sobre:

Ecuación de energía, Darcy–Weisbach, Colebrook–White y accesorios por el método Le/D de Crane.
Sistemas en serie multitramo y clasificación Clase I, II y III.
Tres ejemplos guiados y tres prácticas para resolver con la calculadora del curso.
Protocolo de digitación para evitar errores de unidades y datos precargados.
Actividad final por equipos sobre potencia y NPSH en Bogotá.
Respuestas desplegables, notas del docente y bibliografía.
Uso
Abra 
presentacion_sistemas_tuberias_serie_2026.html
 en un navegador actualizado. No requiere instalación.

Atajos principales: flechas o espacio para navegar; F, pantalla completa; O, índice; N, notas del docente; R, mostrar u ocultar respuestas; y P, imprimir.

Los ejercicios utilizan la aplicación académica Hidráulica de Tuberías en Serie v2.0, también accesible mediante el código QR incluido. Se recomienda conexión a internet para abrir la calculadora, las fuentes y la imagen del diagrama de Moody.
